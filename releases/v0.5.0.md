# PhishSense v0.5.0 (Milestone 5)

Release date: November 15, 2026. Annotated Git tag: `v0.5.0`.

- T20: session accuracy, average response time, confidence distribution and difficulty breakdowns.
- T21: learner-owned completed-session history and descriptive comparisons.
- T22: atomic, idempotent ten-response completion and protected next-session starts.
- T23: results with classification outcomes, recorded reasoning and practice areas.
- T24: training history with completed and in-progress sessions.

Validation: 69 automated tests passed, zero failures and zero skips against a
separate disposable Supabase project. Production preservation hashes matched;
temporary test schemas were removed. Manual testing and screencast completed.

No schema migration, historical backfill, adaptive threshold change or group-rule
change. Existing unmarked legacy sessions remain excluded from completed-session
comparisons. Results are descriptive; elapsed time includes interruptions.
Researcher administration, exports and formal assessments remain future work.
