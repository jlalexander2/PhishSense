# PhishSense v0.4.0 (Milestone 4)

Release date: November 10, 2026. Annotated Git tag: `v0.4.0`.

## Completed functionality

- Supabase PostgreSQL storage with verified TLS; existing Flask authentication retained.
- Approved five-response adaptive evaluation using accuracy, time and confidence.
- Performance-independent control schedule, ten-email sessions and sequential completion.
- Twenty-seven approved scenarios, including eight advanced items with matched-pair exclusion.
- Immediate educational feedback with reasoning/confidence and progress recording.
- Per-learner recurring missed-phishing/false-alarm summaries at two occurrences,
  including exact stored metadata associations where available.

Existing historical sessions and training protocol versions are preserved. The
application release number does not replace stored algorithm/protocol versions.
This release does not add researcher dashboards, exports or Milestone 5 features.

## Validation

The completed build passed 52 Supabase tests with zero failures or skips, plus
synthetic Chrome workflow checks. See TESTING.md and MISTAKE_TRACKING.md. This
release-label update changes documentation and version metadata only; it does not
repeat database migrations/imports or modify application behavior or test data.

## Known limits

The advanced pool has no spare independent capacity for five-hard blocks and
needs expansion/pilot validation before participant research. Elapsed response
time includes interruptions. Pre/post assessments, researcher administration,
results/history dashboards and formal study evaluation remain future work.
Historical intermittent pooler refusals have not been conclusively explained;
subsequent validation succeeded without weakening TLS.

Credentials, databases, local demo login details and generated recording assets
are excluded from the repository. See README.md for setup and submission materials.
