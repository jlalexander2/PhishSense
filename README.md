PhishSense 

PhishSense is an adaptive phishing awareness training application developed as a Computer Science MAster's capstone project at Full Sail University.

Project Overview

The application will provide simulated phishing and legitimate email scenarios to help users practice identifying suspicious messages. 

Planned Features:
user registration and authentication
simulated phishing email exercises 
phishing classification and confidence ratings
personalized educational feedback
adaptive scenario selection
performance tracking and training history

Proposed Technologies:
Python
SQLite
Browser-baed user interface

Development Status

Currently in the planning and initial development stages.
